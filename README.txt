soham-portfolio/
├── index.html        <- all text (about, education, experience, skills, email)
├── css/style.css     <- colours + fonts (top of file, :root)
├── js/main.js        <- animations (rarely needs editing)
└── assets/
    ├── showreel.mp4  <- your video (exact name)
    ├── poster.jpg    <- optional thumbnail shown before play
    └── resume.pdf    <- your resume (exact name)

Open index.html in a browser to view. To publish: upload the whole folder
to Netlify / GitHub Pages / Cloudflare Pages.
Note: resume preview needs the files served normally (works when opened
locally in Chrome/Edge/Firefox; some mobile browsers show the Download link instead).
